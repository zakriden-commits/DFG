# DENI ISLAM — 3D онлайн-игра для Android (2 игрока)

Суровая мультяшная криминальная песочница от первого лица: дом с двумя кроватями, улица с жителями,
оружейный магазин, банк с кассиршей и охраной, полиция со звёздами розыска, подработки с ящиками,
инвентарь, шкафы-сейвы и голосовой чат в онлайне на двоих.

**Готовый файл:** [`DENI_ISLAM.apk`](DENI_ISLAM.apk) (в корне репозитория, ~293 КБ, версия 1.1, подписан v1+v2, minSdk 24 / targetSdk 33).

## Что нового в 1.1

* **Починен выход из дома.** Над дверным проёмом (а также над входами в банк и магазин) стоял невидимый
  коллайдер перегородки — пройти было физически невозможно. Теперь проёмы свободны, дверь шире (2.2 м),
  снаружи появилось крыльцо и лампа над дверью.
* **Машины больше не стоят в домах и не лежат криво.** Все припаркованные машины стоят ровно вдоль бордюра
  в парковочной полосе, развёрнуты по улице и не перекрывают ни один вход (дом, банк, магазин, склад).
  Заодно убран столб-фонарь, который стоял ровно в дверях оружейного магазина.
* **Живая дорога.** По городу постоянно ездят гражданские машины (крутятся колёса, горят фары) и два
  полицейских патруля. Машины тормозят перед тобой, пешеходами и друг другом.
* **Полиция приезжает, а не появляется.** По тревоге со стороны города выезжает патрульная машина
  с мигалкой и сиреной; в HUD видно `🚔 НАРЯД В ПУТИ · ~6 с`. Она доезжает, паркуется, и из неё
  по одному выходят копы. Если розыск снят — они возвращаются в машину, и она уезжает.
* **Анимации копов.** Достают и удерживают ствол двумя руками, стреляют с отдачей, вспышкой и трассером,
  перезаряжаются (опускают оружие), бьют дубинкой вблизи, отходят, если ты подошёл вплотную.

## 1. Установка APK на телефон

1. Скинь `DENI_ISLAM.apk` на Android-телефон (кабель, Telegram «себе», облако).
2. Открой файл в проводнике → «Установить».
3. Android спросит про «неизвестные источники» — разреши для проводника/браузера.
   Play Protect может предупредить (приложение не из Google Play) → «Установить всё равно».
4. Запусти «Deni Islam». Игра стартует в ландшафтной ориентации, во весь экран.

Если при запуске чёрный экран — обнови **Android System WebView** (и Chrome) в Play Маркете:
игра 3D-шная и требует WebGL2, который даёт системный WebView.

> Требуется интернет для онлайна (голос + синхронизация игроков). Без интернета игра работает в одиночку.

## 2. Онлайн на двоих

* Одна комната на весь мир: `deniislam-city-room-1` (1 сервер = 2 места).
* Первый, кто нажал «ИГРАТЬ», становится **хозяином комнаты** — он **Джентельмен** (костюм, шляпа, очки).
* Второй автоматически подключается к этой же комнате — он **Гопник** (спортивки, кепка, семечки-стиль).
* Соединение P2P (WebRTC), сигналинг — публичный PeerJS-сервер, есть STUN/TURN. Если сервер недоступен,
  игра честно скажет «СОЛО» и даст играть одному.
* При входе в игру **каждый раз** спрашивается доступ к микрофону. Разрешил — весь матч друг тебя слышит.
  Микрофон отключается только при выходе из игры (как и просили).
* Ты не можешь ранить напарника: свои пули и удары по второму игроку не проходят.

## 4. Что в игре

**Дом.** Вы просыпаетесь вдвоём на двух кроватях (анимация: лежите → встаёте), камера вступления показывает комнату.
Дверь на улицу открывается/закрывается — закрытая дверь помогает сбросить розыск. Два шкафа по 15 ячеек:
вещи в них сохраняются между смертями и выходами. Кровать = сон (лечит) + сохранение.

**Улица.** Прохожие трёх типов — пожилые (с тростью), обычные, «плохие» (в капюшоне): ходят по тротуарам,
поворачивают голову на тебя, комментируют, разбегаются от ствола. Припаркованные машины, фонари, деревья,
лавочки, баки, светофоры, остановка.

**Подработка.** Возле грузовика на складе стоит бригадир: берёшь ящики и тащишь в кузов — за каждый платят
(сумма случайная, за весь заказ бонус). Иногда прохожий сам подходит и предлагает работу (не часто, но и не редко),
в том числе к твоему напарнику.

**Оружейный магазин.** Продавец + каталог с 3D-превью: пистолет «Гроза» (9мм), дробовик «Кабан» (12к),
автомат «Вихрь» (7.62), нож, дубинка, патроны (дёшево, по 30 шт.), сумка для денег, бронежилет. Модели оружия
висят на стойках в магазине, у каждого — цена и описание.

**Банк.** Большой зал: три кассы с кассиршей, два охранника с дубинками ходят по маршрутам, сейф, кресла, растения.
На стойках лежат деньги. Логика:
* кассирша видит оружие в руках → паника → тревога → полиция;
* охрана видит оружие или как ты гребешь деньги → бьёт дубинкой;
* охрана тебя не видит, если ты у неё за спиной (конус зрения + проверка стен);
* **голыми руками**: удерживай «ДЕЙСТВИЕ» 15 секунд → 5 пачек денег в инвентарь;
* **с сумкой в руках**: 30 секунд → вся наличка уходит в сумку (сумма в разы больше);
* пачки денег в инвентаре → «ПЕРЕВЕСТИ В БАЛАНС» (сумма случайная: иногда много, иногда мало);
* сумка → «ОТКРЫТЬ СУМКУ»: видно всю сумму, можно вывести сколько хочешь или всё;
* через ~3,5 минуты деньги в банке появляются снова.

**Розыск.** 0–5 звёзд. Тревога — 2 звезды, труп — +1, коп — +2. Полиция приезжает на машинах-спавнах и идёт по следу:
до 2 звёзд — дубинки, от 3 — стреляют. Скрылся с места преступления и тебя не видят 14 секунд (в доме с закрытой
дверью — 7) → звезда снимается, на нуле полиция уезжает и сирена стихает.

**Смерть.** Инвентарь полностью теряется (оружие, деньги-пачки, сумка), розыск сбрасывается, через несколько секунд
очнешься на своей кровати. Деньги на балансе и вещи в шкафах остаются.

**Сохранения.** Автосейв каждые 12 секунд, при сворачивании, выходе и смерти. В APK сохранение идёт через
Java-мост в SharedPreferences (надёжнее, чем localStorage на `file://`), в браузере — в localStorage.

**Инвентарь.** Нижняя панель: слот 1 — всегда кулак, дальше оружие/сумка/деньги. Выбрал кулак — видишь кулак,
выбрал ствол — видишь ствол (вид от первого лица с моделями, отдача, вспышка, трассеры, синтезированный звук).

## 5. Структура репозитория

```
DENI_ISLAM.apk          готовая подписанная сборка
game/                   исходники игры (Three.js, ES-модули)
  src/main.js           точка входа: меню, запуск матча
  src/game.js           игровой цикл, игрок, стрельба, банк, магазин, UI-логика
  src/world.js          город: дом, банк, магазин, склад, улицы, свет
  src/models.js         персонажи (9 видов), оружие, машины, деревья, реквизит
  src/npc.js            ИИ: прохожие, охрана, кассир, полиция, продавец, бригадир
  src/inventory.js      предметы, слоты, шкафы, сохранения
  src/net.js            PeerJS: комната на 2 игрока + голосовой чат
  src/ui.js             HUD, меню, модалки, тач-управление
  src/audio.js          весь звук синтезируется (WebAudio), без файлов
  test/                 headless-тесты (логика мира, персонажей, игрового цикла)
android/                Android-проект (smali, манифест, иконка)
tools/build_apk.sh      сборка игры → APK → подпись
tools/sign_apk.py       подпись APK (v1 JAR + v2 APK Signature Scheme) на Python
```

## 6. Сборка

```bash
cd game && npm i                 # three, peerjs, esbuild
bash ../tools/build_apk.sh       # соберёт DENI_ISLAM.apk
```

Скрипт использует JDK (`jdk4py`) и `apktool`, потому что полноценного Android SDK в окружении сборки нет:
smali-обёртка + aapt + собственная подпись APK. Для веб-версии:

```bash
cd game && npm run build && npm start   # http://localhost:3000
```

## 7. Ключ подписи

`tools/deni-key.pem` и `tools/deni-cert.pem` лежат в репозитории намеренно: это самоподписанный
ключ сборки (не для Google Play). Благодаря этому все следующие сборки имеют **ту же подпись**,
и обновление ставится поверх старой версии без удаления — сохранения не теряются.

## 8. Честные заметки

* Вес APK ~290 КБ, а не 30 МБ: в игре нет ни одного файла текстур/звука — город, модели и звук
  генерируются кодом. Это не «демка», а полная сборка на ~4800 строк; вес тут ничего не решает.
* Онлайн работает через публичный PeerJS-сервер (сигналинг) + P2P. Если у провайдера закрыт WebRTC —
  останется соло-режим.
* Голосовой чат — WebRTC-аудио внутри того же соединения; в WebView требуется разрешение микрофона
  (приложение спрашивает его при старте).
* В песочнице, где собиралась игра, нет GPU-браузера, поэтому визуальная проверка делалась программным
  растеризатором сцены (см. `game/test/preview.mjs`), а логика — headless-тестами игрового цикла.
