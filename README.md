# DFG

Боец / 3D-функция в стиле "ragdoll": реалистичный скелет на 17 костей поверх Meshy_AI_UFC_Warrior, анимации бега и падения в стиле ragdoll.

## Источник

`google_drive/Meshy_AI_UFC_Warrior_1122124213_texture.glb` — исходная модель бойца (1 меш, 3 текстуры, 33 131 вершина, 57 294 треугольника, без скелета).

В `.gitignore` — исходник не коммитится; результат в `assets/fighter-ragdoll.glb`.

## Что сделано

**`scripts/build-ragdoll.mjs`** — Node-скрипт, который:
- разбирает исходный GLB (JSON + BIN),
- строит скелет из 17 костей: `hips → spine → chest → neck → head`, `shoulder → elbow → wrist` (R/L), `thigh → knee → ankle` (R/L),
- вычисляет обратные квадратные веса top-4 для всех вершин,
- генерирует инвертированные матрицы привязки (inverse-bind),
- пишет две анимации:
  - `run` — 0,60 с, петля, 9 ключей на трек (вес тела + качание обеих конечностей),
  - `fall` — 1,50 с, "вперед", 17 ключей на трек + трансляция таза вниз и вперёд (forward face-plant, ragdoll-стиль),
- сохраняет как `assets/fighter-ragdoll.glb`.

**`index.html`** — локальный демо-сайт: показывает скелет и обе анимации через three.js + Vendored GLTFLoader. Кнопки: пауза, падение (1 раз), сброс. Вращение + масштаб мышью, горячие клавиши: `Пробел` (пауза), `F` (падение), `R` (сброс).

## Запуск

```bash
node scripts/build-ragdoll.mjs   # пересобрать assets/fighter-ragdoll.glb
python3 -m http.server 8137      # открыть http://localhost:8137/
```

## Ограничения (честно)

- **Бицепс-скелет** — движение плеч/ног через ротации, без имитации мышечной биомеханики.
- **Падение — скриптованный, "кинематический" ragdoll**, а не физичный симулятор (не вшит физ-движок). Но анимация имеет запасное движение (количе + тряска) и плавную "forward face-plant".
- **Не photoreal** — стиль скелет принят сходный с цельной геометрией; точную анатомическую прокладку нельзя извлечь из тупиковых вершинных меша без UV/маркеров.
- Версия: Meshy AI UFC Warrior (один встроенный меш); скелет — QA приближённая постановка.

## Состав (без лишних файлов в git)

- `assets/fighter-ragdoll.glb` — результат, готовая модель с костями и двумя анимациями.
- `scripts/build-ragdoll.mjs` — порождающий скрипт.
- `scripts/vendor-*.js` — Vendored GLTFLoader + BufferGeometryUtils (как в Three.js, только импорты перенастроены на этот fallback путь).
- `vendor/three.module.js` — Vendored Three.js (без CDN).
- `index.html` — одностраничный демо-сайт.
