# DFG — 3D-проекты

Репозиторий с 3D-сценами на **Three.js** (WebGL, без установки — всё работает в браузере).

## 1. Риг персонажа + ходьба

Демо: `npm run dev` → `http://localhost:5173` (или `npm run serve` — собранная версия,
у неё относительные пути и её не ломают прокси/iframe превью).

Что умеет:

- **загружает GLB** — из `assets/models/character.glb` автоматически, либо кнопкой
  «Загрузить GLB» (файл можно просто перетащить в окно);
- **находит кости** в любом гуманоидном скелете: Mixamo, Blender, UE, Rigify, самописный
  (см. `src/anim/humanoidRig.js`);
- **сохраняет встроенный idle** из модели, а если его нет — генерирует процедурный;
- **строит походку** на two-bone IK (`src/anim/walkClip.js`): стопа ставится точно на землю,
  шаг не проскальзывает, высота таза подстраивается под длину шага;
- **играет готовый клип walk, если он уже есть в GLB** (например, `assets/models/character.glb`);
- **переключает idle ↔ walk** по скорости с плавным смешиванием весов;
- движение по сцене на **WASD**, камера — ЛКМ и колесо;
- **экспортирует GLB** с обоими клипами (idle + walk) кнопкой «Скачать GLB».

Пресеты походки: `stalker` (быстрая, тяжёлая, «маньячная») и `calm`.

### Michael Myers: что лежит в репозитории

`assets/models/character.glb` — модель Myers с ригом (91 кость, Rigify-подобные имена,
масштаб в сантиметрах) и двумя клипами:

| клип | источник | длительность |
|---|---|---|
| `Idle` | родной `C4D Animation Take` из исходного GLB | 8.33 с |
| `walk` | процедурная походка `stalker`, запечённая в файл | 0.8 с |

Цифры ходьбы на этой модели: скорость **1.99 м/с** (7.2 км/ч), шаг 0.79 м, каденс 2.5 шага/с,
подъём стопы 13.5 см, покачивание таза 7.3 см, контакт подошвы с землёй — **0.5 мм**,
шов цикла — 0. Скорость демо подстраивается под клип, чтобы стопы не скользили.

Пересобрать модель и проверить её:

```bash
npm run model:probe     # паспорт рига: кости, длины, посадка на землю, скорость шага
npm run model:sheet     # раскадровка ходьбы по реальной геометрии (test/_walk_sheet.png)
npm run model:export    # запечь walk в assets/models/character.glb (idle остаётся как есть)
npm run verify:export   # проиграть файл миксером и проверить контакт стоп с землёй
```

Исходники моделей из Drive лежат в `google_drive/` и в репозиторий не попадают.

### Если экран пустой

На странице снизу слева есть служебная строка, а в левой панели — значение **3D**:

- `WebGL2 ✓` — 3D живой, проблема в чём-то другом (ищи красную плашку с текстом ошибки);
- `НЕДОСТУПЕН` — браузер не выдал 3D-контекст: открой страницу в отдельной вкладке,
  в iframe превью 3D иногда блокируется политикой окружения.

Рендер запускается до загрузки модели: сначала видны небо, луна и лес, потом приезжает
персонаж. Если GLB не приехал за 15 с — показывается манекен, экран не остаётся пустым.

### Проверка модели без браузера

```bash
npm run inspect:glb assets/models/character.glb   # паспорт: кости, анимации, размеры
npm run walk:sheet                               # раскадровка цикла на манекене
npm run test:smoke                              # прогон рига + клипа + микшера
npm run model:sheet                             # раскадровка на реальной модели
npm run verify:export                           # проверка запёкшегося GLB
```

`inspect-glb` — собственный парсер GLB без зависимостей: показывает, есть ли `skins`/`joints`,
иерархию костей, конвенцию имён, все встроенные анимации и их длительность.

## 2. Первое лицо — погоня

Страница: **`/first-person.html`** (из демо рига — кнопка «Первое лицо →»).

Ты в ночном лесу с фонариком, Michael Myers идёт за тобой. Правила погони
(`src/fps/chase.js`, проверяются в `test/fps-chase.mjs`):

- пока ты дальше 4.8 м — он идёт к тебе со скоростью клипа `walk` (около 2.3 м/с);
- подошёл на 3.2 м — **встаёт и смотрит**, дальше не идёт;
- отошёл — снова идёт;
- его скорость всегда равна скорости проигрывания клипа, поэтому стопы не скользят
  ни во время разгона, ни во время остановки (расхождение 0.0000 м/с в тесте).

Управление: **WASD** — идти, **Shift** — бежать (бегом можно оторваться, шагом — нет),
**мышь** — обзор, **Esc** — отпустить курсор, клик — вернуть.

На экране: компас со стрелкой на него и дистанцией, его состояние, красная рамка
и сердцебиение, когда он близко. Звук — процедурный (WebAudio): гул, ветер, его шаги.

```bash
npm run chase   # проверить логику погони без браузера
```
