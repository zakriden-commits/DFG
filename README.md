# NAREZKA SASNOGO 🌈✂️

**Сайт, который сам делает ролики-нарезки из YouTube-интервью.**
Вставляешь ссылку → жмёшь «СОЗДАТЬ НАРЕЗКИ» → получаешь 5–10 сильных моментов по ≤ 30 секунд с жирными вшитыми субтитрами.
Можно написать, какой момент нужен («хабиб про Конора», «про бой с Тибау») — найдём и отметим бейджом 🎯. Не нашли — честно скажем и нарежем то, что считаем сильнейшим.

> Сайт называется **NAREZKA SASNOGO** и светится радугой. Потому что может.

## ⚠️ YouTube из песочницы/сервера без доступа — читай сначала

Если при вставке ссылки видишь `Unable to download API page ... TLS/SSL EOF` —
это не баг сайта: у хостинга нет сетевого доступа к YouTube (проверено: youtube.com,
youtu.be, googlevideo.com, ytimg — все закрыты). Решений три, выбери любое:

1. **Запусти сайт у себя** — дома YouTube доступен:
   ```bash
   ./run.sh          # или Docker (см. ниже)
   ```
   и ставь ссылки на видео — всё качается и режется локально.
2. **Скачай видео любым способом** (yt-dlp на своей машине, сервисы) и загрузи
   файл во вкладке **«📁 Файл с компьютера»** на сайте. К видео можно приложить
   субтитры `.srt/.vtt`; без них включи авто-распознавание:
   `WHISPER_MODEL=small ./run.sh` (нужен `pip install faster-whisper`).
3. **Google Drive**: положи видео в свой Drive и скажи ассистенту название файла —
   он скачает его (до 100 МБ) и прогонит через нарезку прямо в этой среде.

## Быстрый старт

```bash
git clone <repo> && cd DFG
./run.sh            # создаст .venv, поставит зависимости, поднимет на :8000
```

Открой **http://localhost:8000**.

Или вручную:

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Требования: **Python 3.10+**. ffmpeg ставится автоматически через `imageio-ffmpeg`
(системный `ffmpeg` тоже подойдёт). Для субтитров нужен жирный шрифт —
Debian/Ubuntu: `sudo apt install fonts-dejavu-core` (обычно уже стоит).

## Мгновенное демо без YouTube

Кнопка **«Мгновенное демо»** на сайте (или ссылка `demo` в API) собирает из
зашитого в репозиторий синтетического интервью (AI-голос, 3 минуты,
*никаких реальных людей — всё сгенерировано*) и прогоняет весь пайплайн:
анализ → нарезка → жирные субтитры. Отлично подходит для проверки, что всё работает.

## Как это работает

1. **Скачивание** — yt-dlp тянет видео до 1080p + авто-субтитры (ru/en).
2. **Транскрипт** — WebVTT парсится, «катящиеся» авто-субтитры склеиваются в реплики.
3. **Анализ моментов** (два движка):
   - **Офлайн-анализатор** (по умолчанию): эмоциональная плотность реплик
     (исповедь / шутка / боль / дерзость), русская лексика + IDF-взвешивание
     твоего описания: редкие слова («Тибау», «Конора») весят больше частых («хабиб»),
     есть морфология и синонимы («смерть» ↔ «умер» ↔ «не стало»).
   - **LLM-движок**: задай `OPENAI_API_KEY` (или `ANTHROPIC_API_KEY`) — и моменты
     выбирает большая языковая модель, которая понимает контекст по-человечески.
4. **Нарезка** — ffmpeg режет по границам фраз (≤ 30 сек), вшивает белые **жирные**
   субтитры на полупрозрачной плашке снизу, нормализует звук (loudnorm),
   сохраняет H.264 + AAC, шлёт быстрый старт для веба.
5. **Результат** — галерея клипов: тема (🔥 мотивация / 😢 грусть / 😂 смешно / ⚔️ дерзко…),
   авто-описание «что происходит в клипе», бейдж 🎯 если клип попал под твоё описание,
   фильтры, скачивание `.mp4` и `.srt`.

### Про 🎯 «По запросу»

- Совпадения ищутся по всему транскрипту; отмечаются **до трёх** самых сильных.
- Если ничего не найдено — сайт прямо скажет об этом в баннере и покажет
  «просто лучшие» моменты (без выдумывания тем, которых в видео нет).
- Точность офлайн-режима — на уровне ключевых слов; для смыслового поиска
  («чтобы было про предательство») подключи LLM через переменную окружения.

### Переменные окружения

| Переменная | Зачем |
|---|---|
| `OPENAI_API_KEY` | LLM-выбор моментов (OpenAI-совместимый API) |
| `OPENAI_BASE_URL` / `OPENAI_MODEL` | Свой эндпоинт / модель (по умолчанию `gpt-4o-mini`) |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | Альтернатива: Anthropic (по умолчанию `claude-3-5-haiku-latest`) |
| `NAREZKA_DATA` | Куда складывать скачанные видео и клипы (по умолчанию `./data`) |
| `PORT` | Порт для `run.sh` (по умолчанию `8000`) |

### Способ 2 — загрузка файла (без YouTube)

Вкладка **«📁 Файл с компьютера»** на сайте, или напрямую:

```bash
curl -X POST http://localhost:8000/api/jobs/upload \
  -F "video=@interview.mp4" \
  -F "captions=@interview.srt" \   # необязательно
  -F "description=хабиб про Конора" \
  -F "clip_count=8"
```

Переменные для распознавания речи локально (для видео без субтитров):

| Переменная | Значение |
|---|---|
| `WHISPER_MODEL` | `tiny` / `base` / `small` — включить локальное распознавание (по умолчанию выкл) |
| `WHISPER_LANG` | язык речи, по умолчанию `ru` |

### API (кратко)

- `POST /api/jobs` `{url, description?, clip_count?}` → `{job_id}` — создать нарезки из YouTube
- `POST /api/jobs/upload` (multipart: `video`, `captions?`, `description?`, `clip_count?`) → `{job_id}` — создать нарезки из файла
- `GET /api/jobs/{id}` → прогресс, лог и (когда готово) `result.clips[]`
- `GET /api/jobs` → последние задания
- Клипы раздаются с `/media/<job_id>/clip_01.mp4`
- Swagger: `/api/docs`

## Ограничения и честность

- YouTube блокирует некоторые датацентровые IP — на обычной машине пайплайн работает,
  на урезанном сервере без доступа к YouTube — демо-пример и офлайн-анализатор.
- У видео должны быть субтитры или авто-субтитры (ru/en).
- Права на исходный ролик — у автора. Нарезки — для личного пользования и
  добросовестного цитирования, с указанием источника.
- Демо-интервью сгенерировано нейросетью и не является реальным высказыванием
  Хабиба Нурмагомедова.
