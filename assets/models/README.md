# 📦 Сюда кладём 3D-модели

## Куда закинуть персонажа

**Путь:** `assets/models/character.glb`
**Ветка:** `arena/e0cbc734-dfg`

Через GitHub (в браузере):

1. Открыть репозиторий → переключатель веток → выбрать **`arena/e0cbc734-dfg`**.
2. **Add file → Upload files**.
3. Перетащить `character.glb` (в поле имени можно сразу вписать `assets/models/character.glb`).
4. Commit directly to the branch → **Commit changes**.

Любое другое имя тоже подойдёт (например `hero.glb`) — я найду файл сам.
Ограничение GitHub на файл — 100 МБ; если больше, скажи, сделаем через LFS.

Альтернатива: просто прикрепить `.glb` в чат — файл попадёт в рабочее пространство.

## Что дальше

```
npm run inspect:glb assets/models/character.glb
```

Скрипт покажет: версию GLB, узлы, есть ли `skins` (скелет), список костей,
какие анимации уже встроены, размеры модели в метрах и материалы.
