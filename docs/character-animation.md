# Персонаж: риг + ходьба, сохранение готового idle


## 2. Проверка «по логике» — сразу после загрузки

```bash
npm run inspect:glb assets/models/character.glb
```

Скрипт `tools/inspect-glb.mjs` (без зависимостей, читый Node) читает GLB-контейнер и печатает:

- геометрию: вершины, треугольники, материалы, габариты в метрах;
- есть ли `skins` → **кости**, сколько их, иерархию, конвенцию имён
  (Mixamo / Blender / UE / Rigify / своя);
- все встроенные анимации: имя, длительность, каналы, какие кости двигаются;
- отдельно флаги **idle** и **walk/run**;
- вердикт и план действий.

Проверено на синтетических моделях: риг с idle, статичный меш без костей, модель с готовой
ходьбой — все три случая распознаются корректно. Отчёт дублируется в `character.report.json`.

## 3. Сценарий A — кости есть, ходьбы нет (самый вероятный)

1. Разбираю rest pose: длины костей, ориентацию осей, точку земли по стопам.
2. Генерирую `AnimationClip("walk")` **на существующем скелете**:
   - 4 фазы шага (contact → down → passing → up) × 2 стороны, бесшовный цикл;
   - согласованные углы бедро/колено/стопа, чтобы стопа не «шаркала» и не проскальзывала;
   - противоход рук, противофазное вращение таза и плеч, лёгкий наклон корпуса;
   - вертикальное покачивание таза 2× за цикл.
3. Встроенный idle **не трогаю** — он остаётся как есть.
4. `AnimationMixer` + crossfade idle ↔ walk по скорости, walk → бег по желанию.
5. Экспорт итогового GLB (idle + walk) через GLTFExporter.

## 4. Сценарий B — костей нет

Авто-риг: определяю ориентацию и пропорции по bbox и кластерам вершин, строю скелет
(hips → spine → chest → head, плечи/руки, бёдра/голени/стопы), раскладываю веса по расстоянию
до костей со сглаживанием, затем генерирую idle + walk. Это дольше и требует проверки
деформаций (локти/колени), поэтому делаю с итерациями по скриншотам.

## 5. Критерии качества (проверяю до сдачи)

- [ ] цикл бесшовный: поза кадра 0 = позе последнего кадра;
- [ ] стопа в контакте не проскальзывает (foot slide < 1 см на шаг);
- [ ] нет «резиновых» коленей и вывернутых суставов;
- [ ] амплитуды правдоподобные (бедро ~±22°, колено 0…55°, стопа ~±15°, плечо ~±18°);
- [ ] переходы idle ↔ walk плавные (0.2–0.3 с crossfade);
- [ ] 30 fps бейк, цикл 1.0–1.2 с для шага.

### Текущие метрики пресета `stalker` (синтетический риг 1.8 м)

| Параметр | Значение |
|---|---|
| Длительность цикла | 0.80 с (2.5 шага/с) |
| Длина шага | 0.725 м |
| Скорость без проскальзывания | 1.81 м/с |
| Подъём стопы в переносе | 0.127 м |
| Погружение подошвы | ≤ 0.016 м |
| Ошибка замыкания цикла | 0.00002 м |
| Наклон корпуса | ~8–12° |
| Мах рук | ~7° (руки почти неподвижны) |
| Наклон головы набок | 9° |

### Метрики на реальной модели Michael Myers (`assets/models/character.glb`)

Модель из Sketchfab: 91 кость, Rigify-подобные имена (`RIG_01`, `Spine1_03`, `LeftArm_09`),
единицы — сантиметры (94.09 ед/м), рост 169.4 ед = 1.8 м, встроенный idle 8.33 с.

| Параметр | Значение |
|---|---|
| Длительность цикла `walk` | 0.80 с (2.5 шага/с) |
| Длина шага | 0.794 м |
| Скорость без проскальзывания | 1.99 м/с (7.15 км/ч) |
| Подъём стопы в переносе | 0.135 м |
| Ошибка касания подошвы (замер по скиннингу) | 0.5 мм |
| Покачивание таза | 0.073 м |
| Шов цикла idle↔walk и walk сам с собой | 0 (последний кадр = первому) |
| Треков в клипе | 20 (19 костей + сдвиг таза) |

Что пришлось учесть именно для этой модели (и это же — типовые грабли):

- **сантиметры**: все допуски в коде заданы долями длины ноги, а не метрами;
- **rest-поза со смещёнными костями корпуса** (Spine1_03 стоит на 3 см сзади таза) —
  поэтому наклон считается по фактическим костям, а не по «идеальному» скелету;
- **кисти/стопы**: подошва считается по реальным точкам пятки и носка через дельту
  кватерниона от rest, а не по оси кости;
- **руки в A-позе** (плечо 10–12° от вертикали): выворот задаётся отдельным `armOut`;
- **IK-коррекция в два прохода**: после решения ноги подошва доводится до нужной высоты.

### Следующие шаги после загрузки модели

1. `npm run inspect:glb assets/models/character.glb` — паспорт.
2. Открыть демо: модель подхватится сама, клип построится под её пропорции.
3. Подогнать амплитуды под конкретную модель (длина шага, наклон корпуса, голова).
4. Проверить деформации на сгибах (локти, колени, плечи) и при необходимости
   поправить полюс колена / угол стопы.
5. Отдать GLB с двумя клипами.
